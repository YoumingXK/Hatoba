## Hatoba 0.4.3

## The master password minimum

Setting a master password asks for **8 characters** again; it had been raised to 12. The strength meter still warns below a score of 2, which is what the specification asks for (SEC-09), so a short password is allowed rather than blocked.

## The AI's memory

Each entry of the memory note carries the day it was last saved (`updated="YYYY-MM-DD"`), so the assistant can tell a fact from this morning from one from last month.

## The built-in skill's translations

The labels the assistant is taught to name now live in `references/labels/` files, written from the app's own message tables: renaming a label fails a test until the skill is written again, which is how the assistant keeps naming things the way your interface does.

Installed versions update to this version from **Settings → About**. The sync Worker hasn't changed, so there is nothing to redeploy.
